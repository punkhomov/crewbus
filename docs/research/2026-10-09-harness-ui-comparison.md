# UI открытых agent harness’ов

Дата исследования: 2026-10-09. Исследованы публичные исходники и документация; приложения не запускались, зависимости не устанавливались. DeepSeek здесь означает **deepseek-ai/deepseek-harness**.

## Результат

DeepSeek Harness и OpenCode имеют собственные дизайн-системы. Goose строит собственный интерфейс поверх shadcn/Radix. Поэтому собственная визуальная система совместима с использованием готовых примитивов.

| Проект | Основа интерфейса | Применимость к Crewbus |
| --- | --- | --- |
| DeepSeek Harness | React, CSS Modules, clsx; отдельные ui-theme и ui-primitives, семантические `--dsw-*` токены | Подходящий пример интерфейса агента и будущих субагентов; перенос базовых компонентов требует проверки упаковки, тем и зависимостей |
| OpenCode | SolidJS, Kobalte; собственный `@opencode-ai/ui`, темы и компоненты | Источник идей по компоновке и состояниям; компоненты Solid нельзя непосредственно использовать в React |
| Goose | React, Tailwind 4, shadcn/Radix и собственная тема | Пример собственной визуальной системы на той же основе, что выбрана для Crewbus |
| OpenHands / Agent Canvas | React, HeroUI, Tailwind 4 | Референс интерфейса управления разными агентами; готовые элементы основаны на другой UI-библиотеке |
| Lobe UI | Отдельная React-библиотека `@lobehub/ui`, Ant Design и antd-style | Альтернативная библиотека компонентов; её внедрение требует пересмотра основы UI, чтобы избежать двух параллельных систем |

## DeepSeek Harness подробнее

В `docs/web-styling.md` прямо задано: **“Use CSS Modules and clsx; do not add a component library or Tailwind.”** Это правило DeepSeek для его репозитория, а не ограничение Crewbus.

Тема владеет глобальными цветами, типографикой, отступами, скруглениями, тенями и движением. Feature-компоненты используют семантические aliases. Общие кнопки, поля, меню, модальные окна и рендереры вынесены в ui-primitives.

README ui-primitives описывает компоненты без импорта Cordis runtime, с обычными props, локализованными подписями от вызывающей стороны и токенами темы. Но пакет предназначен как вход сборки Web-shell: внешнему потребителю нужно обеспечить сторонние зависимости и стили. Изученный package.json также содержит Cordis peer dependency и workspace-ссылки. Простое подключение пакета в независимый React/Vite-проект пока не проверено.

Высокоуровневые ui-chat, ui-tool и ui-subagent используют композицию Cordis, слоты и протоколы сессий DSH. Их перенос в Crewbus потребует замены интеграционного слоя; наличие React само по себе не делает их готовым чатом для pi.

Для будущего гипервизора полезны следующие решения:

- Отдельное дерево субагентов с происхождением от родительской сессии; обычный список диалогов не заполняется всеми дочерними сессиями.
- В строке субагента показываются состояние, токены и длительность; разговор можно открыть рядом с основным.
- Для поддерживаемых дочерних сессий есть дополнительные сообщения и независимая остановка.
- Общий вид вызова инструмента дополняется специализированными рендерами отдельных инструментов; ошибки и прерывания остаются явно видимыми.

## Почему DeepSeek запрещает Tailwind

Дополнение от 2026-10-12 по [архитектурной заметке Web styling system](https://github.com/deepseek-ai/deepseek-harness/blob/d743267388641bc76f17c45ce8b4c231aed1d32c/.agents/notes/archived/process/2026-07-19-web-styling-system.md).

**Что прямо сказано в источнике:** стили GUI пишут агенты и проверяют ревьюеры; отдельного дизайнера нет. Без проверяемой системы токенов цвета, скругления и анимации расходятся между компонентами, а условия тёмной темы расползаются по реализации. Выбраны CSS Modules + clsx, единое владение темой, динамические значения через CSS-переменные и однозначный checklist для автора и ревьюера. Запрет Tailwind и сторонней библиотеки компонентов входит в эти инженерные ограничения.

**Граница вывода:** документ объясняет выбранную систему целиком, но не даёт отдельного сравнения Tailwind с CSS Modules и не заявляет о технической непригодности Tailwind. Сокращение числа способов написать одинаковое оформление — наша интерпретация этих ограничений.

Заметка архивная: её начальная схема токенов впоследствии заменена на `--dsw-*`, а актуальные правила находятся в `docs/web-styling.md`. Старые решения о нетокенизированных размерах и отступах не следует переносить как текущие правила DeepSeek.

**Контекст Crewbus:** пользователь попросил сохранить это объяснение и результаты сравнения. Запрет Tailwind не становится требованием Crewbus. Для выбранного shadcn/Tailwind полезны единые семантические токены, централизованная тема, общие компоненты и проверяемые правила оформления. Выбранный стек сохраняется; перенос компонентов DeepSeek остаётся отдельным исследованием.

## Предложение для Crewbus

Сохранить выбранные React/Vite, shadcn/ui и выборочные AI Elements как основу MVP. Поверх них определить токены Crewbus и собственные композиции чата, вызова инструмента и тудушек. События и состояние принадлежат Crewbus/pi; компоненты отвечают за представление.

Использовать DeepSeek Harness как основной референс дерева субагентов и просмотра дочерних разговоров, OpenCode — компоновки и отображения инструментов, Goose — настройки shadcn под собственный продукт. Эти наблюдения не расширяют MVP: управление субагентами остаётся следующим этапом.

Если предпочтение сместится к оформлению DeepSeek, сначала отдельно проверить переносимость ui-primitives/ui-theme на небольшом примере. Решение о замене выбранной UI-основы пока не принято.
